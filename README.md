# 나의 마음 키우기

초등학생 생명존중교육을 위한 마음 식물 키우기 게임입니다.

## 실행
index.html을 브라우저에서 열거나 GitHub 저장소에 올리고 Vercel에서 연결하세요. Framework Preset은 Other, Build Command는 비워두고 Output Directory는 기본값을 사용하세요. 외부 라이브러리와 로그인 없이 실행됩니다.

## 수업 흐름 (20~30분)
- 도입: 모든 마음이 소중하다는 이야기 나누기 (3분)
- 씨앗부터 열매까지 7단계 활동 (15~20분)
- 식물 이름 붙이기, 이미지 저장, 원하는 학생만 소개하기 (5분)

## 기능
예시 선택 및 직접 입력, 랜덤 꽃 5종/열매 4종, 자동 저장, PNG 다운로드, 이미지 보기, 새로 시작. 식물은 마음 성장의 상징이며 실제 식물 생육을 재현하지 않습니다.

## 참고
입력한 글은 이 기기 브라우저에 저장됩니다. 공용 기기는 활동 후 새 씨앗 심기로 초기화하세요. 시크릿 모드나 브라우저 데이터 삭제 시 저장 내용은 사라질 수 있습니다. 다운로드가 막히면 이미지 보기 후 길게 눌러 저장하세요.

## 수채화 이미지
배경, 성장단계별 화분과 식물 12칸 아틀라스, 열매 4종 아틀라스를 직접 생성해 적용했습니다. 배경/식물/열매 파일은 assets 폴더에 포함되어 있습니다.
