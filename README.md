# 나의 마음 키우기 · 마음꽃

초등학생 생명존중교육 마음 정원 게임.

## 배포
압축을 풀어 index.html과 assets 폴더를 GitHub 저장소 루트에 올린 후 Vercel에서 연결합니다. Other 프레임워크, 빌드 명령 없음, 출력 경로 기본값으로 배포합니다. 로그인 및 외부 라이브러리 없이 실행됩니다.

## 수업 흐름
첫 화면 안내 → 오늘의 마음 → 장점 → 듣고 싶은 말 → 나에게 주는 격려 → 마음 돌봄 → 나누고 싶은 말 → 기억하고 싶은 마음.

## 성장 효과
씨앗 심기: 모종삽, 흙 구덩이, 씨앗 낙하와 흙 덮기. 새싹과 마음 돌봄: 작은 반짝임. 물주기: 물뿌리개와 흐르는 물방울. 격려: 햇살. 꽃 피우기와 완성: 꽃잎 반짝임. 각 효과는 약 2초간 재생 후 식물이 부드럽게 성장하며 재생 중 중복 제출을 막습니다. 기기의 동작 줄이기 설정을 켜면 애니메이션을 생략합니다.

## 꽃
튤립, 해바라기, 데이지, 장미, 종꽃, 물망초의 다른 모양 중 한 종류가 정해집니다. 6단계부터 완성까지 같은 꽃이 유지됩니다. 열매는 없습니다.

## 완성
상단에 마음꽃 이름을 입력하고 작품을 저장합니다. 마음꽃과 7개 말풍선 구성의 1600×1020 PNG입니다. 이미지 보기 기능도 제공합니다.

## 참고
같은 브라우저에 자동 저장됩니다. 공용 기기는 저장 후 새 씨앗 심기로 초기화하세요. 모든 제작한 수채화 이미지가 assets 폴더에 포함되어 있습니다.

직접 입력을 기본으로 합니다. 예시는 입력칸 아래에서 생각이 잘 안 나면 예시 보기를 눌러 펼칩니다. 선택한 문장도 수정할 수 있습니다.
