# 나의 마음 키우기 · 마음꽃

초등학생 생명존중교육 마음 정원 게임.

## 배포
압축을 풀어 index.html과 assets 폴더를 GitHub 저장소 루트에 올린 후 Vercel에서 연결합니다. Other 프레임워크, 빌드 명령 없음, 출력 경로 기본값으로 배포합니다. 로그인 및 외부 라이브러리 없이 실행됩니다.

## 수업 흐름
오늘의 마음 → 장점 → 듣고 싶은 말 → 나에게 주는 격려 → 마음 돌봄 → 나누고 싶은 말 → 기억하고 싶은 마음. 꽃 종류는 처음 시작할 때 5종 중 정해지고 6단계부터 완성까지 유지됩니다. 열매는 없습니다.

## 완성
화면을 넓게 사용하여 마음꽃과 7개 말풍선을 보여 줍니다. 이름을 붙인 후 1600×1020 PNG를 저장합니다. 이미지 보기 기능도 제공합니다. 최대 70자 입력이 말풍선에 들어가도록 글씨 크기가 조정됩니다.

## 참고
같은 브라우저에 자동 저장됩니다. 공용 기기는 저장 후 새 씨앗 심기로 초기화하세요. 수채화 배경과 식물 이미지가 assets 폴더에 포함되어 있습니다.
